# TiHuMoon 鹈鹕赏月 · 项目计划（PLAN）

- 版本：0.1.0 ｜ 更新：2026-09-25 ｜ 分支：main（唯一主分支）
- 规则：每次对话结束必须 commit 一次，并同步勾选本文件阶段状态 + CHANGELOG.md

## 1. 项目目标
杭州中秋赏月指南 Demo：鹈鹕骑自行车带领学院成员逛 6 个赏月点，串联「3D 开场 → 赏月 → 灯谜 → 做花灯 → 放飞祝福」，演示时长 **5–10 分钟**（可略超）。

## 2. 硬性约束
| # | 约束 |
|---|---|
| 1 | 移动端优先，竖屏/横屏均需适配 |
| 2 | 进度/昵称/祝福用 localStorage 记忆 |
| 3 | 灯谜**只有 JHWL 一条**（用户原稿逐字保留，三选项全对+礼盒 gag；不得增改任何其它灯谜） |
| 4 | 用户三张参考图**仅作参考**，不上站；图片资产用搜集/生成图 |
| 5 | 仅 main 一个分支；每次对话后提交一次版本 |
| 6 | 任何不明确的问题必须先向用户提问 |
| 7 | **开发者不自行运行 build/dev/测试，一切测试与验收交给用户** |

## 3. 技术栈（已确定）
| 层 | 选型 | 说明 |
|---|---|---|
| 构建 | Vite 8 | Windows 下 `npm.ps1` 被封锁，统一用 `npm.cmd` |
| 框架 | Vue 3.5（SFC + Composition API） | 不用 UI 库 |
| 3D | Three.js 0.186 | 开场程序化低多边形鹈鹕+自行车 |
| 样式 | 原生 CSS + CSS 变量 | 令牌见 DESIGN.md |
| 路由 | 不用 vue-router | 自研章节状态机，**线性播放、不可自由跳转** |
| 存储 | localStorage | keys 见 DESIGN.md §7 |
| 字体 | 霞鹜文楷嵌入 | `font-display: swap` + 系统兜底，Phase 8 |
| 数据 | GBK→UTF-8 静态模块 | `src/data/users.js`、`blessings.js`（各 200 条） |
