### 天空处理对照表（决定怎么拍）
| 照片 | 我会在天空叠什么 | 拍摄要求 |
|---|---|---|
| 湖畔夜景（hero 底图） | **代码画的月亮+星星**、标题文字、动态 SVG 鹈鹕骑车 | 天空**留空、不要拍月亮**，越干净越好（少云、少光带）；路/湖/山景集中在下半部 |
| 4 站赏月点夜景 | 不叠月亮；只在**画面底部**压半透明文字渐变条、左上角序号徽章 | 主体（塔/阁/桥/江）放**中上部**，下 1/3 相对干净；**月亮可有可无**（拍到了也保留，卡片不冲突） |
| 放飞夜空（竖版） | **代码画的大月亮**、上升孔明灯、星星闪烁 | 天空**大面积留空、不要拍月亮**；底部保留山影/树影剪影 |
| 月亮特写（P2） | 单独当素材抠图用（hero/放飞二选一替换代码月） | 可以拍月亮；前几张若都没带月亮，这张就是月亮素材来源 |
| 灯笼特写 | 不涉及天空 | 正常拍即可 |

- 一句话版：**hero 和放飞背景「天空必须干净无月」；6 站卡片随意；想拍月亮就单独拍一张特写。**
- 同一场景若有月亮，方便的话各拍一张（带月/不带月）备选。
- 存放：统一放 `public/assets/photos/`，文件名拼音（如 `pinghujianyue.jpg`）；原图直传，裁剪/调色/叠加由代码完成
- 放入照片后跑 **`npm run photo`**（`scripts/analyze_photo.py`）：输出每张的亮度/天空干净度/EXIF/**亮斑候选坐标**（疑似月亮）+ JSON；我据此配月亮锚点并筛掉不合格图——无需肉眼也能技术验收，审美由你最终把关
- 拍摄时任选时间点即可，**不阻塞当前开发**（Phase 3 纯程序化，无需图片）
